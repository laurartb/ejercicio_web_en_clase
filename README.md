
# 🌸 PETUNIA — Floristería de barrio

**Petunia** es una floristería de barrio con una larga tradición familiar, donde las flores acompañan los pequeños y grandes momentos de la vida.

Fundada en 1976 por la abuela Petunia, hoy sus nietas, Lili y Rosa, continúan su legado, combinando la esencia de una floristería tradicional con una mirada fresca y contemporánea.

> Donde los momentos florecen.

## 🌷 Sobre el proyecto

Este proyecto se ha desarrollado para la asignatura **Maquetación Web con Hojas de Estilo**, del Grado en Diseño Multimedia y Gráfico de **UDIT**, durante el curso académico 2026/2027.

El objetivo es diseñar y desarrollar una página web responsive para un comercio de barrio, utilizando Tailwind CSS, estilos propios y JavaScript.

La web de Petunia busca transmitir cercanía, tradición y delicadeza mediante una identidad visual propia, una navegación sencilla y una experiencia adaptada a diferentes dispositivos.

## 🌼 Secciones de la web

- **Inicio:** presentación de Petunia, categorías, productos destacados, novedades e información de la floristería.
- **Tienda:** catálogo de ramos de flores y talleres florales.
- **Servicios:** encargos y propuestas florales para celebraciones, ceremonias y eventos.
- **Sobre nosotros:** historia de Petunia y de las generaciones que han mantenido vivo el negocio.
- **Contacto:** formulario para consultas y encargos personalizados.

## ✨ Funcionalidades

- Diseño responsive desarrollado con enfoque *mobile first*.
- Navegación adaptada a escritorio y dispositivos móviles.
- Menú desplegable para pantallas pequeñas.
- Alternancia entre modo claro y modo oscuro.
- Sistema de diseño personalizado con colores y tipografías propias.
- Animaciones de aparición al hacer scroll mediante GSAP y ScrollTrigger.
- Animaciones CSS creadas con `@keyframes`.
- Efectos interactivos `hover` y `focus`.
- Navegación entre las diferentes páginas de la web.
